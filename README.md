
# SmartEnergy AI

### Intelligent Household Energy Consumption Prediction and Analysis Using Machine Learning

## Project Overview
SmartEnergy AI analyzes historical household electricity consumption data and predicts future energy requirements using machine learning.

## Features
- User registration and login
- Household electricity consumption dashboard
- Daily and monthly consumption analysis
- Energy consumption prediction
- Electricity cost estimation
- Data-driven energy-saving recommendations
- Machine learning model comparison

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Random Forest
- Linear Regression
- Pandas and NumPy
- Plotly
- MySQL

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```

## Database
Create a MySQL database named `smartenergy_db` and configure your credentials in `.env`.
